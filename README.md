# Dustwar

Three.js ile yapılmış, üstten görünümlü bir çöl dövüş oyunu.

**Oyna:** https://ahmetyasary.github.io/dustwar/

## Kontroller

| Tuş | İşlev |
|---|---|
| Ok tuşları | Hareket · Shift: koş |
| Boşluk | Yumruk |
| A / D | Kamerayı döndür |
| W / S | Kamera açısı |
| Tekerlek | Yakınlaş / uzaklaş |
| M | Sesi kapat / aç |
| K | Tiki kapat / aç |
| B / T | Kum fırtınası / tik (test) |

## Geliştirme

```bash
npm install
npm run dev      # yerel geliştirme sunucusu
npm run deploy   # derle ve GitHub Pages'e yayınla (gh-pages dalı)
```
